# Professional Store Request Lifecycle

This revision presents one Store Requisition document through focused role views:

- Requester: create drafts, add items, submit, and track own requests.
- Department Head: review item quantities, approve, reject, and view the document history.
- Stores Manager: compare requested, available, approved, and issued quantities and manage shortages.
- Store Keeper: create issue vouchers, build pick lists, dispatch stock, and record handover.

The interface now includes a structured item matrix, canonical status labels, concise task sections, a document activity timeline, and mobile-responsive request summaries. Tutorial-style numbered stages and role explanation banners were removed from operational forms.
