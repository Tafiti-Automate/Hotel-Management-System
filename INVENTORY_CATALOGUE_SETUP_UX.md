# Inventory Catalogue Setup UX

The Cost Controller catalogue workflow is now explicit:

1. Create Major Group
2. Create Item Group under a selected Major Group
3. Create Item under a selected Item Group

The Inventory Catalogue Setup page presents these as three separate actions. The Create Major Group form hides the parent field. The Create Item Group form requires a Major Group. The Create Item form requires both a Major Group and an Item Group and filters the Item Group choices to the selected Major Group.

The Cost Controller sidebar and dashboard link directly to Inventory Catalogue Setup.
