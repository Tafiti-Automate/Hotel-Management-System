# Client Materials Control report catalogue
Screenshot-derived menu: Purchase Analysis (10), Stock Analysis (15), Sales Analysis (7), Result (12). Booking Journal appears twice. Shared read-only report access for Cost Controller and Financial Manager; financial approvals, payment actions and GL exports are not broadened. Twelve new report IDs with scoped operational sources, including booked month-end snapshots and department consumption. Existing report titles corrected to distinguish current stock valuation from monthly balance, and low stock from out of stock. Reports center grouped in menu order.

Limitations: original report print samples were not provided. Issue deviations are department request deviations; inter-store transfer deviation/reason code schema is not present. Forecast and cover are indicative 30-day usage only. Document-date history uses accounting date, not independently verified source document date. Monthly store balance uses booked opening/closing snapshots; detailed movement reconciliation remains in month-end workspace. Sales tax has no captured source data. Sales/activity, F&B Result, Daily Food, cost-center comparisons and purchase analysis require further business definition and detail review. F&B Budget displays configured procurement caps, not a certified F&B budget. Custom Reports and Report Batches are not implemented. Both reports and operations need witnessed client acceptance. No financial posting is performed by these report endpoints.
