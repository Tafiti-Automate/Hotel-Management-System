# Client feedback — stock register, recipes and reporting

- Both Store Keeper and Cost Controller use the same Stock on Hand view. Hide the separate SOH column in table/mobile/detail while retaining inventory balances for availability, controls, valuation and financial reports. Expose article/store metadata and recorded WAC from the stock balance API. Issued/transferred quantity is cumulative posted outbound issue/transfer/dispatch ledger quantity; no reservations or sales are counted.
- Recipe creation now selects a production department explicitly. Ingredient stock source remains a separate required choice for actual inventory costing and POS depletion, not a department substitute. Legacy recipes remain unassigned until reviewed; no department is inferred from a store name. The Department master has no property link; API enforces existing outlet/property scope and department leadership own-department selection.
- Shared report viewer now has search, detailed-record view, grouped summary, and matching exports. This is a shared presentation layer, not a claim that every source report already contains complete line-level detail or all relevant additive financial measures. Summary counts are records rather than transactions. Approved additive amounts are whitelisted; mixed units/rates/running balances are not totaled.
- Remaining: audit all report families and add true line-level reports and reconciled totals where absent; extend search to module-specific screens and selectors; get the next report batch from client. Department variance accounting must distinguish F&B cost of sales and operating expenses through explicit department/GL mapping, verified opening/issues/returns/closing and previously recognized costs. Current consumption-only booking does not post duplicate expenses. No new department variance journal or automatic reclassification in this change.
- No production data correction or inferred financial mapping has been performed. CI and client acceptance remain required.

Additional staged changes: the five transaction registers now expose scoped article-level detail and grouped summaries with recorded line values where authorized. Month-end departments show source-linked consumption and posted return reversals; Finance explicitly classifies the net recorded cost as expense or cost of sales, and approval freezes evidence for booking. This is a classification and reconciliation report, not a new GL journal; direct receipt/issue costs are not charged a second time. Legacy booked cycles are not retroactively assigned a classification. Unmapped GL account posting and full report catalogue acceptance remain separate.
