# Fixed assets stage
Opening register requires a verified posted GL opening journal dated at a month end. The Financial Manager registers individually evidenced assets and their three mapped accounts; the supplied fifteen category rates are UI defaults, not confirmed accounting policy. Straight-line monthly charge is capped at cost less residual and prior accumulated depreciation. Only posted journals contribute to depreciation and net book value; drafts use existing independent approval and posting. Each asset/month is unique. Reconciliation compares register cost and accumulated depreciation to mapped GL accounts, not the completeness of all hotel assets.
No asset data is seeded. Additions, disposals, revaluations, write-offs, bulk runs, correction/reversal and exact client layout remain future work. Indirect cash flow, integrated source posting and POS/PMS remain outstanding.
