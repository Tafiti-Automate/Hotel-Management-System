# Department GL integration — staged 24 November 2026

The IT integration workspace supports department-specific expense and COGS mappings with actual property account codes. Booked month-end classifications select the department mapping in the inventory GL preview and export. General mappings remain available for prior workflows without a booked classification. A classified department missing a mapping blocks export. Signed transit pickup is recognized as consumption, not dispatch; legacy pickup valuation uses original signed issue evidence only, and ambiguous/duplicate evidence blocks export. New pickup ledger entries capture valuation. Export rows carry the department dimension and divergent repeat exports for a closed period are blocked.

Limitations: the historical return workflow does not retain original account allocation per returned lot, so cross-period mapping changes need Finance reconciliation. Direct receipts remain on the invoice-side accounting path, not an extra consumption journal. Actual chart of accounts must be supplied by Finance. No external GL import or production account codes have been configured. Full GL reconciliation and client acceptance remain outstanding.

New dispatch ledger entries record both asset movements at verified historical cost; new unvalued dispatch is rejected. A potentially cross-period departmental return now blocks export until the original GL account allocation is reconciled. This is intentionally conservative rather than guessing a historical debit account. Reconciliation tooling for these exceptions is still required.
