# GRN A4 Landscape Print Fix

The Goods Received Note print layout has been adjusted specifically for A4 landscape output.

Changes applied:

- Uses A4 landscape with a 7 mm print margin.
- Removes the application sidebar, header and workspace spacing from the printed page.
- Resets the application page animation/transform during printing so the GRN starts at the top of the printable area.
- Uses the full printable width without horizontal clipping or shrink caused by the on-screen layout.
- Keeps the GRN header, document details, item table, VAT totals, signature section and footer together in a clean landscape layout.
- Improves print font sizing and physical spacing using print units for better readability.
- Does not change GRN workflow, receipt/posting logic, VAT calculations or other procurement logic.
