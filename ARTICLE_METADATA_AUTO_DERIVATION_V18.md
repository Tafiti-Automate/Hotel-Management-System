# Article metadata auto-derivation

The Store Request item form now treats category and base issue unit as article-master metadata.

- The requester chooses only the article and quantity.
- Category is read automatically from the selected Article.
- The base issue unit is read automatically from the selected Article.
- Neither category nor unit is submitted as a requester-selected category field.
- Category remains visible in the request summary for identification and reporting.
- Existing draft lines retain their stored unit where one already exists.
